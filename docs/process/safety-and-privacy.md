# Safety and privacy

The rules are in [../../rules/safety-and-privacy.md](../../rules/safety-and-privacy.md): what agents may do on the maintainer's Mac, what never enters this repository, and what the app itself may do on a user's Mac. That file is the only copy. The git rules that belong with them are in [../../rules/git.md](../../rules/git.md).

## Because the repository is public from the start

The repository was public from its first commit. These are facts about the project, not rules for agents, and each is done as early as it can be:

1. The name is checked early in phase 0: App Store, GitHub and trademarks.
2. `README.md` says what the app is, how to build it and how to report a problem.
3. Private vulnerability reporting is switched on in the repository settings, with the owner's yes.
4. A ruleset protects `main` (card 1). See [checks.md](checks.md).
